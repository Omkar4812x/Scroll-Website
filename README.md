# 📜 NOCTURNE — Luxury Scrollytelling Web Experience

> **An immersive, scroll-driven interactive storytelling web app composed in six movements, showcasing luxury product narrative design powered by custom scrub engine animation.**

---

## ✨ Key Features

- 🌙 **Cinematic 6-Movement Narrative**
  - **7:42 PM - The Invitation**: *The city is waiting.*
  - **8:06 PM - Outside**: *Bergamot & bitter orange top notes.*
  - **9:18 PM - The Turn**: *Iris, rose absolute & saffron heart notes.*
  - **11:47 PM - After Midnight**: *Cedar & smoked vetiver base notes.*
  - **1:03 AM - The Morning After**: *20% parfum oil longevity.*
  - **The Next Night - Begin Again**: Interactive call-to-action shop finale.

- 📜 **Custom Scrub-Engine Animation**
  - Ultra-smooth scroll interpolation (`scrub-engine.js`) driven by user scroll depth.
  - Dynamic ambient color shifts, SVG still transitions, and typography fade effects.

- 🎨 **Minimalist Luxury Aesthetic**
  - Georgia serif display typography paired with deep dark mode background, warm gold accents, and fluid mobile viewport responsiveness.

- 🛠️ **Scrollytelling Engine Reference & Plugin**
  - Includes reusable scrollytelling reference components and Claude skill plugin (`claude-plugin/`) for generating custom scroll experiences.

---

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, Canvas/SVG Scrub Engine
- **Engine**: Custom `mountLetsScroll` Scrollytelling Scrub Engine
- **Styling**: CSS Variables, Glass & Ambient Glow Tokens

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Omkar4812x/Scroll-Website.git
   cd Scroll-Website
   ```

2. **Launch Application**:
   Simply open `index.html` in any modern web browser or serve via Live Server.
